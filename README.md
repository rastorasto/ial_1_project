# IAL — Homework 1

Data structures homework in plain C, written against the course-provided test
harnesses.

| Task | Structure |
|------|-----------|
| `c201` | Singly linked list |
| `c203` | Character queue on a static array |
| `c206` | Doubly linked list + extension |

## Build

```bash
cd c201        # or c203 / c206
make && make test
```

Coursework for *Algoritmy (IAL)* at FIT VUT Brno. C11, no external libraries.
